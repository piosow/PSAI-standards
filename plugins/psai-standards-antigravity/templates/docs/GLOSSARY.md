# Glossary

Definitions of domain and project terms used in code and documentation.
Entries are sorted alphabetically. Add a term when it first appears in the project.

Entry format:

```
### Term
Definition in one to three sentences.
Also known as: synonym, abbreviation (optional)
See: [related doc](features/x.md) (optional)
```

---

### Changelog
The file `docs/CHANGELOG.md` recording every behavior-affecting change, grouped by release.
See: [CHANGELOG](CHANGELOG.md)

### Complexity tier
Rating of a task from XS to XL that drives model selection and whether the work is split into orchestrated subtasks.
See: [instructions.md, section 9](../instructions.md#9-planning)
